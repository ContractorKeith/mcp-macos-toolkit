# Code of Conduct

## Our Standard

We want a practical, respectful community for macOS users, local-AI builders, MCP implementers, and contributors of all experience levels.

Examples of welcome behavior include:

- Giving specific, constructive technical feedback.
- Respecting different levels of macOS, security, and software experience.
- Testing assumptions and correcting mistakes without making disagreements personal.
- Protecting personal data shown in logs, screenshots, fixtures, and bug reports.
- Disclosing security concerns privately.

Unacceptable behavior includes harassment, discriminatory language, threats, publishing another person's private information, spam, trolling, and knowingly encouraging unsafe use of local automation.

## Scope

This Code of Conduct applies in repository issues, pull requests, discussions, documentation, and any community space operated for this project.

## Enforcement

Maintainers may edit or remove content, close contributions, limit participation, or block accounts when behavior harms the project or community. Report conduct concerns privately through the maintainer's GitHub profile. Include relevant links and context, and do not expose unrelated personal data.

## Safety Note

Security disagreements should be handled with evidence and care. Do not publish working exploits or personal data while a vulnerability is being triaged. Use the private process in [SECURITY.md](SECURITY.md).

This policy is informed by the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
